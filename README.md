✨ Overview

To-Do List & Task Manager helps users organize daily activities by creating, updating, completing, and deleting tasks. The application provides a modern interface with fast performance and a responsive design.

🚀 Features
✅ Add New Tasks
✏️ Edit Existing Tasks
✔️ Mark Tasks as Completed
❌ Delete Tasks
🔍 Search Tasks
📅 Organize Daily Work
💾 MySQL Database Support
📱 Mobile Responsive UI
⚡ Fast & Lightweight
🎨 Clean Dashboard

Open phpMyAdmin.
